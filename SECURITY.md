# Security Policy

## Versões suportadas

Correções de segurança são aplicadas na **última versão publicada** (ver a aba *Releases*).
Enquanto o projeto estiver em **alpha / pre-release**, apenas a `main` é suportada.

## Reportar uma vulnerabilidade

**Não abra uma issue pública.** Reporte de forma **privada**, por um destes canais:

- **GitHub Security Advisories** (preferido): aba **Security → Report a vulnerability** neste repositório.
- Inclua, se possível: passos de reprodução, versão afetada, impacto esperado e uma prova de conceito.

Nos comprometemos a:

- confirmar o recebimento em até **72 horas**;
- avaliar o relato e informar um prazo de correção;
- conduzir a correção em **divulgação responsável/coordenada**;
- creditar quem reportou (se assim desejar).

Obrigado por ajudar a manter o SetrixDB seguro.
